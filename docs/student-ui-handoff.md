# 4 号前端交接

本分支基于 `main` 的 `2b74b9f`，供 1 号通过 PR 集成。后端接口、NASA 归一化、HAC 统计和服务器 PDF 实现均未修改。

## 最终行为

- 新加坡概念岛、问题、观察、验证和结论使用连续的灰绿/深绿视觉。滚动推进、章节进入、曲线绘制和按钮反馈由原生 CSS/JS 实现，没有滚轮劫持或自动播放视频。
- 桌面章节导航；手机底部导航；键盘可以使用年份滑杆或左右方向键逐点查看观测。手机图表采用独立的可读 viewBox。减少动态效果偏好会关闭过渡和视差。
- 数据通过现有 `/api/catalog`、`interpret`、`investigate`、`tutor`、`report` 接口读取。统计仍由服务器计算；观察图中只有用户点击揭示后才出现拟合线和统计卡。
- 所有统计数字使用普通小数/千分位；极小 p 值显示 `< 0.001`，0.05 附近的舍入不得改变显著性边界。
- 排除年显示年份和具体缺失月份，不再展示 JSON。缺口不会用折线桥接成连续观测。
- 结论反馈紧邻按钮展开；加载、失败和完成均有就地说明。`no_key`、`timeout`、`auth`、`http_error`、`bad_response` 显示不同说明，结论文本不被替换。
- 修改问题/城市/变量/年份立即清除旧证据并取消相关请求；版本标记拒绝过期响应。学生文字保留并提示重新核对。修改文字时，旧反馈失效。
- 含糊问题解析的未识别字段会清空，必须人工选择。解析不会自动运行调查。
- 调查完成要求有效统计、已揭示、勾选已阅读以及非空学生结论。没有有效证据也保留现有服务器“不完整 PDF”导出能力。

## 运行与检查

按根目录 README 安装依赖并启动 FastAPI。没有新增前端 npm 依赖。

```sh
python scripts/verify.py
node --check app/static/app.js
node --check app/static/ui-utils.js
node --check app/static/snapshot-preview.js
node --test tests/test_ui.cjs
```

需要真实 NASA 网络验证时按 README 设置 `RUN_LIVE_NASA=1`。

本次本地结果：

- `RUN_LIVE_NASA=1 python scripts/verify.py`：81/81 通过，0 跳过；包含真实新加坡 2001–2025 测试。
- Node 规则回归：6/6 通过；覆盖普通数字、p 值边界、排除年份、降级原因、无效范围及过期请求标记。
- 实际 HTTP smoke：页面、脚本、接口 schema 和无证据 PDF 通过。
- Chrome：真实新加坡气温及降水均加载 25 年；趋势揭示、就地无密钥反馈、结论保留、改变量后证据失效、PDF 下载通过。
- 实际下载的三页 PDF 已逐页渲染查看：学生原文、图表、来源和年度表存在，没有发现裁切或重叠。本分支没有改 PDF 排版。
- 390×844 手机视口检查无横向溢出；图表为 `420×300` viewBox。

完整外部 AI 服务尚未配置，真实提供商超时/认证错误未在浏览器里制造；其 reason 映射由前端规则测试覆盖，后端错误路径由现有 mock 测试覆盖。过期响应标记有单元测试，浏览器检查了改参数后清空证据；未对每一种网络时序进行自动浏览器测试。

## 共享网站与完整应用的区别

公开 Sites 主机不能运行这个 Python FastAPI 服务，因此共享预览**明确使用仓库的历史真实记录**，不是实时服务。构建：

```sh
python scripts/build_shared_preview.py /absolute/output/dist
```

构建器读取 `evidence/nasa-data/20261114T080209845385Z/results/` 和对应 `raw/`，保留全部 25 组数据、统计、来源和获取时间，附上结果与原始文件 SHA-256。测试逐组比较，保证没有修改数值。预览固定 2001–2025，支持五城市和五变量，并明确标注记录时间。

预览中的指引是预设内容，没有连接外部 AI；PDF 使用浏览器 Print / Save PDF，页面明确区分服务器 PDF。正常 FastAPI HTML 不加载归档适配器，始终使用真实后端 API。组员本地运行应用才能测试任意合法年份、实时 NASA、外部 AI 和服务器 PDF。

主视觉是为本项目生成的概念插画，不是 NASA 图像、真实地形或网格范围，不能作为测量证据。
